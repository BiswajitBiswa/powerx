Executive Overview: Pooling Idle Workstations into an AI Supercomputer

Modern workstations feature high-bandwidth unified memory architectures (16 GB to 128 GB+), but cloud GPUs (H100/A100) are expensive to run continuously. Simultaneously, developer workstations sit idle for hours during meetings, lunch breaks, and overnight.

Because unified architecture chips feature shared physical address spaces between CPU and accelerator, pooling several workstations together creates massive, high-bandwidth memory pools (hundreds of gigabytes) at $0 extra infrastructure cost.

Dual-Engine Co-Scheduling: Model-Bound and Task-Bound Workloads

PowerX introduces a dual-engine architecture solving the fundamental tradeoff between large models and fault-tolerant execution:

1. Model-Bound Engine (Exo Layer Sharding)

Used when a single model exceeds single-node memory (e.g., Llama-3-70B on 16GB nodes). Partitions tensor layers across local LAN with ring streaming.

2. Task-Bound Engine (Ray Micro-Chunks)

Used for distributed fine-tuning (LoRA), embedding generation, and evaluation sweeps. Dispatches 30s-2min chunks that complete cleanly before any user interruption.

Tiered Memory Architecture: Pooling Host RAM, TPUs & GPUs

Modern compute infrastructure separates hardware into two distinct paradigms: Unified Physical Architecture and Tiered Offloading:

Unified Architecture (UMA)
Zero-Copy Physical Memory

CPU and accelerator share the same physical memory bus at 200-800 GB/s, eliminating PCIe latency.

Google TPUs + Host RAM
JAX Host Offloading

JAX parks inactive neural layers in host CPU DRAM and streams tensors just-in-time over PCIe Gen4/5.

NVIDIA GPUs + Host RAM
DeepSpeed & Pie

ZeRO-Infinity unifies VRAM, CPU RAM, and NVMe SSD; Pie prefetches KV caches from CPU RAM.
